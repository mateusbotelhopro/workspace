# Automações

## O que entrega

Fluxos automatizados que substituem trabalho manual repetitivo.

| Tipo | Descrição | Prazo típico |
|------|-----------|-------------|
| Chatbot WhatsApp | Atendimento automatizado, triagem, FAQ | 3-7 dias |
| Funil de vendas | Follow-up automático, recuperação de lead, agendamento | 5-10 dias |
| Integração entre sistemas | Conectar CRM, planilha, e-mail, WhatsApp, etc | 3-7 dias |
| Notificações automáticas | Alertas, lembretes, atualizações por WhatsApp/e-mail | 2-5 dias |
| Automação de processos | Fluxos internos (onboarding cliente, cobrança, relatório) | 5-14 dias |

## Stack

- **Automação**: n8n (self-hosted ou cloud), Make (quando fizer sentido)
- **WhatsApp**: Z-API, WhatsApp Cloud API, ManyChat
- **IA nos fluxos**: OpenAI API, Claude API (pra classificação, respostas, extração)
- **Integrações**: Google Sheets, Notion, Slack, CRMs, e-mail (SMTP/API)

## O que inclui

- Mapeamento do fluxo (o que automatizar e como)
- Construção e teste do fluxo completo
- Deploy em produção
- Documentação do fluxo (o que faz, como editar)
- 1 rodada de ajustes após entrega

## O que NÃO inclui (mas pode adicionar)

- Manutenção mensal dos fluxos — oferecer como recorrência
- Custos de API (WhatsApp, OpenAI, etc) — por conta do cliente
- Treinamento presencial — documentação + vídeo curto de walkthrough
