# Projetos Digitais

## O que entrega

Sistemas sob medida — o cliente tem um problema, a Kortex constrói a solução.

| Tipo | Descrição | Prazo típico |
|------|-----------|-------------|
| MVP / Protótipo | Versão funcional mínima pra validar ideia | 7-14 dias |
| SaaS simples | Plataforma com login, dashboard, CRUD | 14-30 dias |
| App web | Aplicação web completa (não mobile nativo) | 14-30 dias |
| Dashboard / Painel | Painel de dados, relatórios, métricas | 7-14 dias |
| Sistema interno | Ferramenta interna (CRM simples, gestão, controle) | 7-21 dias |

## Stack

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Next.js API Routes, Node.js, Supabase, Firebase
- **Banco de dados**: Supabase (Postgres), Firebase, Prisma
- **Auth**: Supabase Auth, NextAuth, Clerk
- **Hospedagem**: Vercel, Railway, Fly.io
- **Pagamento**: Stripe, Mercado Pago (quando tiver checkout)

## O que inclui

- Arquitetura e modelagem de dados
- Frontend + backend funcional
- Deploy em produção
- Documentação básica de uso
- 1 rodada de ajustes após entrega

## O que NÃO inclui (mas pode adicionar)

- App mobile nativo (iOS/Android) — só web app
- Manutenção e suporte mensal — oferecer como recorrência
- Integrações complexas com sistemas legados — avaliar caso a caso
